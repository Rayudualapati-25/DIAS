# Licences of the data and external material in this repository

Status on 2026-10-09 (plan step 19). This page records what the repository
says about each source. Where the repository has no record, the entry says so;
nothing here was inferred from memory.

## Code

| Part | Licence | Record |
|---|---|---|
| All source code (chaincode, backend, frontend, scripts, testbed, experiments) | Apache-2.0 | `LICENSE`, `CITATION.cff`, each `package.json` |

## Data created for this project

| Data | Where | Nature | Licence |
|---|---|---|---|
| DIAS fine-tuning and evaluation sets | `experiments/dias-finetuning/data-v1/`, `data-v2-binary/`, `adversarial-expanded/` | synthetic; generated by `experiments/dias-finetuning/generate.js` from the written policy (`experiments/dias-finetuning/README.md`); the adversarial set derives variants from 20 synthetic test cases (its `manifest.json`) | covered by the repository licence unless the author chooses a separate data licence — **open author decision** |
| LLM-AC reconstruction | `experiments/cross-dataset/llmac/` | generated by `experiments/cross-dataset/build_llmac.py` from the policy table published in Zisad & Hasan (IEEE CCNC 2026); it is not the LLMAC authors' data | repository licence; the clause wording follows the paper's Table II (comment in the script) |
| Demo users, cases and records | `scripts/seed-*.js`, `testbed/seed/`, `LLMxAI/data/` | synthetic demo data | repository licence |
| Experiment logs, metrics, tables and plots | `experiments/runs/`, `results/` | produced by this project's runs | repository licence |

The generators and READMEs describe all demo and test data as synthetic. This
session did not audit every data file for real personal data.
