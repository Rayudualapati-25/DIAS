# Criminal Investigation Chain report screenshots

These figures were captured from the completed production deployment on
2026-08-20 as full-screen 1920 × 1080 desktop images. The neutral disconnected state
avoids exposing a wallet address or a deployed contract address.

## Suggested figure captions

1. **Overview:** Criminal Investigation Chain overview showing the Solidity
   registry connection workflow and on-chain data-protection model.
2. **Register record:** Authorized interface for registering investigation
   record metadata and a browser-generated SHA-256 content digest.
3. **Verify record:** On-chain query interface for retrieving and verifying a
   registered investigation record.
4. **Manage access:** Smart-contract owner interface for granting or revoking
   record-registration authorization.
5. **Activity log:** Blockchain event view for reviewing recent investigation
   record registrations.

Source deployment: <https://crimechain-solidity-registry.vercel.app/>
