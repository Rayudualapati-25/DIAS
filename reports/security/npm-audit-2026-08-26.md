# npm Dependency Audit — 2026-08-26

## Scope and commands

The audit used the committed lockfiles and production dependency scope:

```bash
cd backend && npm audit --omit=dev --audit-level=high
cd chaincode/crimerecords && npm audit --omit=dev --audit-level=high
cd benchmarks/caliper && npx --yes npm@11.5.1 audit --omit=dev --json
```

The Caliper command used Node.js 22.20.0 and the package-declared npm 11.5.1
controller. No `npm audit fix`, lockfile rewrite, or dependency upgrade was
performed during this audit.

## Decision and controls

The automatic npm recommendation is not applied because it proposes replacing
Caliper CLI 0.7.1 with 0.3.2, an incompatible downgrade that would invalidate
the pinned benchmark controller and require a new reproducibility study.

Current controls are:

- Caliper remains an isolated local benchmarking workspace used only with the
  disposable synthetic Fabric network.
- The benchmark controller and lockfile remain pinned.
- GitHub Actions runs the Caliper validation suite, reports all advisories, and
  fails if a critical advisory appears.
- Dependabot checks the three npm workspaces monthly.
- A Caliper or transitive-dependency upgrade requires rerunning the smoke test,
  measured suite, and provenance checks before results are compared.

This is risk containment, not a claim that the Caliper dependency tree is free
of vulnerabilities.
